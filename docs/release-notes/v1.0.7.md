First public release of **Ultratube**: ad-free YouTube, YouTube Music and Twitch for Android phones and
Galaxy Watch / Wear OS, with experimental desktop and iOS builds.

Only the Android phone and watch apps have been tested on real devices (Galaxy S23, Galaxy Watch 7).
Desktop and iOS builds come straight from GitHub Actions.

## ⚠️ Upgrading from earlier builds

These APKs are signed with Ultratube's new **release key**. Builds shared before this release were
signed with a debug key, so Android will refuse to update them in place: **uninstall the old app once**
(phone and/or watch), then install these APKs. Data kept by the old build (downloads, local history)
is removed with it; subscriptions can be re-imported.

## Highlights

- No ads and no YouTube WebView: own extraction (NewPipeExtractor) and an mpv-based player.
- Real audio-only mode with economy/normal/high audio quality and a mobile-data saver.
- Shorts from the real YouTube feed, SponsorBlock, offline downloads, picture-in-picture, live chat.
- Ad-free Twitch with 7TV/BTTV emotes.
- Optional YouTube account (no API key), subscription import from Takeout, NewPipe and LibreTube.
- Galaxy Watch: standalone player **and** full control of the phone app (queue included).
- New in this build: "Play now" keeps your queue — the video goes right after the current item
  instead of replacing what you queued.

See the [README](https://github.com/gusdslara/ultratube#readme) for installation steps and known limitations.
