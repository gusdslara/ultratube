# Ultratube — material de portfólio

Prints reais (Galaxy S23 e Galaxy Watch 7, 22/11/2026), logo e imagens de destaque prontas
para usar. Tudo em PNG; os prints do relógio já vêm recortados no formato redondo
(fundo transparente).

## Imagens de destaque

| Arquivo | O que mostra |
|---|---|
| [`destaque-celular.png`](destaque-celular.png) | Grade com 6 telas do celular: Início, Assistir, Só áudio, Shorts, Twitch com chat, Ajustes |
| [`destaque-relogio-app.png`](destaque-relogio-app.png) | Grade com 8 telas do app do relógio: tocando, lista de músicas, player, controles, letra, Twitch, conta, entrar com o celular |
| [`destaque-relogio-controle.png`](destaque-relogio-controle.png) | O relógio controlando o Ultratube do celular: controle, fila e escolha de aparelho |

## Logo — [`logo/`](logo)

| Arquivo | Uso |
|---|---|
| `ultratube-icon.svg`, `ultratube-icon-512.png`, `ultratube-icon-1024.png` | Ícone (quadrado arredondado, degradê vermelho) |
| `ultratube-icon-redondo.svg`, `ultratube-icon-redondo-512.png` | Ícone redondo, como no relógio |
| `ultratube-glyph.svg`, `ultratube-glyph-branco-512.png` | Só o símbolo, branco, para fundos de cor |
| `ultratube-wordmark-escuro.png`, `ultratube-wordmark-claro.png` (+ `.svg`) | Ícone + nome, para fundo escuro e claro |
| `ultratube-icone-app-android-1024.png` | O ícone usado no app Android |

Cores: vermelho `#FF0033` (degradê `#FF2A4D` → `#B80025`), fundo `#000000`/`#0A0A0A`,
texto `#F4F4F4`. Os SVG do nome usam a fonte Fira Sans ExtraBold; prefira os PNG se a fonte
não estiver instalada.

## Relógio controlando o celular — [`relogio-controle/`](relogio-controle) (432 × 432)

## Observações

- Os prints da conta mostram o nome e a foto reais da conta conectada.
- O código e o endereço da tela "Entrar com o celular" valem só enquanto aquela tela fica
  aberta.
- Os vídeos, thumbnails e marcas que aparecem nos prints são conteúdo de terceiros
  (YouTube/Twitch), mostrados como uso normal do app.
